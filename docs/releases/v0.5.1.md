# v0.5.1 — rebuild for nginx 1.31.8

Rebuild the v0.5.0 module for **nginx mainline 1.31.8** and retain builds for
**nginx stable 1.30.6**. There are no module or protocol changes. The module
version advances because v0.5.0 has already shipped and published tags are
immutable.

Nginx **1.31.7** users should keep using the signed
[v0.5.0 builds](https://github.com/teian/ngx_http_pow_gate/releases/tag/v0.5.0).
A module must match the exact nginx version, libc and architecture of its
runtime. The v0.5.0 upgrade guidance still applies when upgrading from an older
module version.

Each module includes a `.sig` signature and `.pem` certificate. `SHA256SUMS`
covers all eight modules. The release workflow requires two independent,
byte-identical builds per module and attaches GitHub build-provenance
attestations before publishing.

## Verify

Download your module, its `.sig` and `.pem`, and `SHA256SUMS`, then run:

```bash
module=ngx_http_pow_gate_module-0.5.1-nginx1.31.8-glibc-amd64.so
sha256sum -c --ignore-missing SHA256SUMS
gh attestation verify "$module" --repo teian/ngx_http_pow_gate
cosign verify-blob \
  --certificate "$module.pem" \
  --signature "$module.sig" \
  --certificate-identity 'https://github.com/teian/ngx_http_pow_gate/.github/workflows/release.yml@refs/tags/v0.5.1' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  "$module"
```
