# v0.6.2 — rebuild for nginx 1.31.10 security release

Rebuild the v0.6.1 module for **nginx mainline 1.31.10**, released on
2026-11-23 to fix an nginx security issue. Nginx stable stays at **1.30.7** and
is rebuilt unchanged. There are no module or protocol changes. The module
version advances because v0.6.1 has already shipped and published tags are
immutable.

## nginx security fix

The fix is in nginx itself, not in this module. Upgrade nginx and the module
together; a module must match the exact nginx version, libc and architecture of
its runtime.

| CVE | nginx issue | Fixed in |
| --- | --- | --- |
| CVE-2026-132779 | excessive CPU usage caused by a client when `ssl_early_data` is used | 1.31.10 |

See the [nginx security advisories](https://nginx.org/en/security_advisories.html)
and the [1.31.10](https://nginx.org/en/CHANGES) change log.

nginx 1.31.10 also fixes a bug where nginx might hog CPU when SSL connections
to backends are used.

Nginx **1.31.9** users who cannot upgrade yet can keep using the signed
[v0.6.1 builds](https://github.com/teian/ngx_http_pow_gate/releases/tag/v0.6.1),
but stay exposed to the issue above. Nginx **1.30.7** users do not need to
act: the 1.30.7 modules here are a rebuild of the same code against the same
nginx as v0.6.1.

Each module includes a `.sig` signature and `.pem` certificate. `SHA256SUMS`

byte-identical builds per module and attaches GitHub build-provenance
attestations before publishing.

## Verify

Download your module, its `.sig` and `.pem`, and `SHA256SUMS`, then run:

```bash
module=ngx_http_pow_gate_module-0.6.2-nginx1.31.10-glibc-amd64.so
sha256sum -c --ignore-missing SHA256SUMS
gh attestation verify "$module" --repo teian/ngx_http_pow_gate
cosign verify-blob \
  --certificate "$module.pem" \
  --signature "$module.sig" \
  --certificate-identity 'https://github.com/teian/ngx_http_pow_gate/.github/workflows/release.yml@refs/tags/v0.6.2' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  "$module"
```
